# V3 추천 품질 기준점

이 문서는 서비스 운영 정책이 아니라 V3 추천 결과의 품질을 개선하기 위한 최초 기준점이다. 현재 단계에서는 NDCG/Recall을 측정하지 않고, 의도적으로 만든 사용자 행동과 실제 추천 결과가 같은 방향을 가리키는지 간이 분석한다.

## 1. 분석 범위

- 대상: 모델 학습에 포함된 사용자 24명
- 사용자 유형: `stable`, `mixed`, `drift`, `negative_heavy` 각 6명
- 취향군: 6개 장르 cohort를 유형마다 한 명씩 포함
- 비교 목록: 장기 취향 후보 20개, 독립 단기 취향 후보 20개, 최종 추천 20개
- 제외: 온보딩 전용 및 모델 학습 후 생성된 cold-start 사용자
- 원본 결과: [v3_quality_snapshot_20260827T134350Z.md](diagnostics/v3_quality_snapshot_20260827T134350Z.md)
- 기계 판독 결과: [v3_quality_snapshot_20260827T134350Z.json](diagnostics/v3_quality_snapshot_20260827T134350Z.json)
- 학습 후 행동 분리 결과: [v3_quality_snapshot_20260827T142248Z.md](diagnostics/v3_quality_snapshot_20260827T142248Z.md)

재실행 명령은 다음과 같다.

```bash
docker compose run --rm --no-deps back-seeder \
  python -m app.jobs.recsys.v3.diagnostics.quality_snapshot --limit 20
```

`mean_genre_share`는 추천 영화가 가진 전체 장르 중 사용자 상위 장르와 겹치는 비율이다. 영화에 장르 하나만 겹쳐도 완전 일치로 계산하는 문제를 피하지만, 정답 영화가 있는 정확도 지표는 아니다.

| --- | ---: | ---: | ---: | ---: | ---: | ---: |

파이프라인의 기본 불변식은 통과했다.

- 모든 사용자가 최종 추천 20개를 받았다.
- 이미 본 영화와 `passed` 영화가 다시 노출된 사례는 0건이다.
- 한 사용자 목록 안의 중복 영화는 0건이다.
- 단기 후보 조회 자체는 단기 취향과 비교적 높은 방향 일치를 보였다.

그러나 추천 품질 기준선으로는 아래 문제가 확인됐다.

## 3. 확인된 문제

### Q1. 장기 LightFM 후보의 개인화가 약하다

장기 후보 480칸에서 서로 다른 영화는 79편뿐이었고, 최종 추천 480칸도 108편뿐이었다. 최종 상위 5개 120칸에서는 47편만 사용됐다. `타이타닉`, `피아니스트`, `매트릭스 2`, `갱스 오브 뉴욕` 같은 영화가 서로 다른 취향군에 반복적으로 나타났다.

장기 후보의 LightFM 원점수 절댓값도 최소 약 `9.89e9`, 중앙값 약 `7.07e11`, 95백분위 약 `5.04e12`, 최대 약 `1.43e13`이다. 현재 percentile 정규화가 값의 크기를 가려 최종 계산을 가능하게 하지만, 이 크기는 정상적인 학습 점수로 보기 어렵다. 임베딩 발산 또는 feature 합산 규모 문제를 먼저 확인해야 하며, 정책 가중치 조정보다 우선한다.

정성적으로도 애니메이션·가족 사용자에게 `빅쇼트`, `라라랜드`, `아메리칸 메이드`가 상위에 노출되는 등 장기 후보가 사용자별 취향을 충분히 분리하지 못했다. 반면 공포 사용자와 SF 사용자 일부는 적절한 결과를 보여, 전체 파이프라인 고장보다는 모델 학습 및 개인화 강도의 문제로 판단한다.

### Q2. 유용한 단기 후보가 최종 목록에서 거의 사라진다

단기 후보와 단기 장르의 평균 일치는 `stable 0.778`, `mixed 0.733`, `drift 0.658`로 방향성이 있었다. 그러나 최종 480칸 중 단기 출처가 기록된 것은 18칸뿐이다.

- `model`: 462칸
- `model+short_term_context`: 17칸
- `short_term_context`: 1칸

특히 실제 취향 변화를 만든 `drift` 사용자의 최종 단기 출처 비율이 2.5%에 불과하다. 독립 단기 후보 생성은 동작하지만, 병합·상세 분석·정책 재정렬 과정에서 단기 후보가 충분히 생존하지 못한다. 단기 후보 생성기를 다시 만드는 것보다 후보 병합 후 탈락 지점을 먼저 추적해야 한다.

### Q3. 안정 사용자도 취향 변화로 과대 판정된다

`stable` 사용자의 평균 취향 변화 신뢰도는 `0.528`으로, 실제 변화 사용자 `0.622`와 차이가 작다. 현재 계산은 장르, 키워드, 배우, 감독, 테마, 분위기에서 새로 등장한 값의 비율을 feature 종류별로 동일하게 평균한다.

같은 장르 영화를 계속 봐도 영화가 바뀌면 배우·감독·키워드가 자연스럽게 달라진다. 이 값들이 장르 변화와 같은 비중으로 계산되어 안정 사용자도 변화로 오인될 수 있다. 취향 변화 판단은 장르·테마·분위기 중심으로 재조정하고, 배우·감독·키워드는 보조 신호로 낮추는 검증이 필요하다.

### Q4. 저신뢰 영화가 최종 결과에 과도하게 포함된다

최종 480편 중 `vote_count=0`은 37편, `vote_count<20`은 105편으로 21.9%였다. `UFC on ESPN 33`, `The Hired Gun`, `Kuningas kulkureitten`처럼 사용자 의도와 관계를 설명하기 어렵거나 검증 정보가 부족한 영화가 상위에 포함됐다.

인기 영화만 추천하도록 만들 필요는 없지만, 투표가 거의 없는 영화는 높은 의미 점수만으로 상위에 오르지 않도록 신뢰도 기준을 강화해야 한다. 이 조정은 모델 개인화와 취향 변화 판정이 안정된 뒤 수행한다.

### Q5. 현재 seed cohort는 정답 데이터로 쓰기에 순도가 낮다

시드 영화 풀은 cohort 장르 3개 중 하나라도 포함하면 통과시키고 투표 수 순으로 120편을 뽑는다. 각 영화에서 목표 장르가 차지하는 평균 비율은 0.414~0.550이고, 대부분의 cohort에서 120편 중 86~99편은 목표 장르를 정확히 하나만 갖는다.

예를 들어 `animation_family_adventure`는 어드벤처 하나만 일치하는 실사 영화도 포함할 수 있다. 따라서 현재 장르 일치율은 알고리즘만의 성능이 아니라 시드 오염도 함께 반영한다. 현재 seed는 흐름 및 방향 검증에는 사용할 수 있지만, 고도화 전후의 품질 우열을 확정하는 정답 집합으로 사용하면 안 된다.

| 취향군 | 목표 장르 평균 비율 | 목표 장르 1개만 일치 | 목표 장르 2개 이상 일치 |
| --- | ---: | ---: | ---: |
| action/crime/thriller | 0.414 | 99/120 | 21/120 |
| romance/drama/comedy | 0.497 | 86/120 | 34/120 |
| horror/mystery/thriller | 0.442 | 91/120 | 29/120 |
| animation/family/adventure | 0.434 | 89/120 | 31/120 |
| sci-fi/fantasy/adventure | 0.550 | 47/120 | 73/120 |
| documentary/history/war | 0.435 | 94/120 | 26/120 |

## 4. 품질 고도화 순서

다음 작업은 한 번에 여러 가중치를 바꾸지 않고 아래 순서로 진행한다.

1. **평가 입력 정리**: seed 영화 풀의 장르 순도를 높이고, 동일한 사용자 표본과 출력 형식을 고정한다.
2. **LightFM 안정화**: 원점수 발산 원인을 확인하고 학습률, 규제, epoch, component와 feature 정규화를 조정한다. 원점수 분포와 사용자 간 후보 중복률을 품질 gate로 추가한다.
3. **취향 변화 판정 보정**: 안정 사용자와 변화 사용자가 분리되도록 feature 종류별 비중과 최소 행동 조건을 조정한다.
4. **단기 후보 생존 보정**: 변화 신뢰도에 따라 단기 후보가 병합과 최종 재정렬에서 실제로 남도록 단계별 탈락 수를 계측하고 조정한다.
5. **catalog 신뢰도 보정**: `vote_count=0`과 극소수 평가 영화의 상위 노출을 제한하되 long-tail 자체를 제거하지는 않는다.
6. **동일 표본 재검증**: 24명 결과를 다시 생성하고 장기 개인화, 단기 반영, 제외 규칙, 저신뢰 비율을 이전 기준점과 비교한다.

LightFM 점수와 취향 변화 판정이 불안정한 상태에서 ontology 또는 최종 정책 가중치부터 조정하면 원인을 분리할 수 없다. 첫 구현 작업은 Q1의 학습 상태 진단과 seed 평가 입력 정리다.
